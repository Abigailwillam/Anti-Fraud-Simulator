# 反诈演练 · 案例库与互动模式

一个**双击即可运行**的反诈骗意识训练网页。首页两个入口：

- **诈骗案例库** —— 10 大类、30 条案例，可搜索、可分类浏览、可展开看完整手法拆解
- **互动模式** —— 模拟一部手机，在微信里和诈骗方「好友」对话，规则引擎实时计算风险指数

产物：`dist/scam-sim.html` —— 单文件，零依赖，无需服务器。

## 使用

双击 `dist/scam-sim.html`，从首页选入口。

---

## 一、诈骗案例库

**搜索栏**（顶部）：输入关键词即时过滤，支持空格分隔多关键词（AND 关系）。匹配范围是标题、摘要、分类名、标签、以及正文各处（手法拆解、典型话术、破绽、处置建议）。

> **搜索与分类的关系**（容易误解的一点）：
> 搜索**始终作用于全库**，不管你当前停留在哪个分类。切分类不会缩小搜索范围，
> 只有清空搜索框才会回到「按分类浏览」。
> 这一点由 `searchCases(keyword)` 的函数签名保证——它根本没有分类参数，从类型层面就不允许传入。
> 界面上会明确写「在全库 30 条案例中匹配到 N 条」，不让你猜。

**分类网格**：10 大类，覆盖需求点名的全部类型。

| 分类 | 案例数 | 一句话特征 |
|---|---|---|
| 刷单返利 | 3 | 先给真钱后吃大单 |
| 冒充公检法 | 3 | 借国家权力名义制造恐惧 |
| 虚假投资理财 | 3 | 小额获利建立信任，投入后无法出金 |
| 虚假购物客服 | 3 | 用真实订单信息把退款变成垫付 |
| 网络贷款 | 3 | 放款前收手续费，收完钱人消失 |
| 杀猪盘 | 3 | 长期培养感情，最后导向投资或博彩 |
| 虚假征信与债务 | 3 | 冒充平台代办征信修复，索要手续费 |
| 冒充熟人与领导 | 3 | 盗用身份，语音视频也未必是真的 |
| 中奖退税 | 3 | 凭空送大奖，但要你先交钱 |
| 虚拟币与博彩 | 3 | 境外平台、稳赚话术，只出不进 |

每个分类显示案例数与其中高危案例数。点击进入该分类，面包屑显示当前位置，点「全部分类」可返回。

**案例卡片**：默认显示标题、所属分类、危险度、发布时间、摘要。点击展开完整内容：

- 🔍 **手法拆解** —— 这个骗局分几步走，每步在你这里制造什么心理状态
- 🗣 **典型话术** —— 原话引用，让你下次能「认出声」
- ⚠ **破绽在哪** —— 哪句话、哪个动作暴露了它不是真的
- 🛡 **遇到了怎么办** —— 具体到操作层面的处置建议

**分页**：每页 6 条，底部页码条最多显示 5 个页码按钮，越界自动夹取。

## 二、互动模式

功能与之前完全一致：模拟手机 → 桌面 → 微信 → 好友列表 → 聊天。

- 4 个剧本：冒充公检法、虚假投资、冒充客服、刷单兼职，各含 4 个推进阶段
- 每阶段带话术池、施压话术、**破绽提示**、防范建议，部分阶段触发微信原生动作（发链接、屏幕共享、拉群）
- 规则引擎实时检测危险行为（给卡号、说验证码、同意屏幕共享、发收款码…）并计算风险指数 0-100
- 结束（说「我要报警」或点「拉黑」）后生成复盘报告：暴露的风险行为、阶段推进复盘、走过的阶段里存在的破绽、完整聊天记录

### 规则控场，AI 只负责说话

| 职责 | 由谁决定 |
|---|---|
| 剧情阶段 / 风险评分 / 终止判定 | **规则引擎**（确定性） |
| 把话术说成人话、贴合人设 | **AI**（可选） |

演练结果必须可复现、可评分，所以换任何模型都不影响评估口径。
测试里专门有一条断言：**无论模型说什么，连续质疑都不会推进阶段。**

设置面板在侧栏（不在手机屏幕上），支持任何 OpenAI 兼容的 `/chat/completions` 接口。
AI 越界有三层防护（prompt 硬约束 → 输出正则校验 → 二次脱敏），任一触发或网络失败都自动降级为内置话术。

## 目录

```
kb/scenarios.js      互动模式知识库：好友设定、4 个剧本、微信话术、破绽 + sanitize()
kb/cases.js          案例库数据：10 分类、30 案例、手法/话术/破绽/处置
engine/rules.js      规则引擎：意图分类、风险检测、阶段推进、风险评分（纯函数）
engine/ai.js         AI 层：人设 prompt 编译、输出清洗、越界检测、OpenAI 兼容调用
engine/session.js    互动会话状态机：规则控场 + AI 话术，自动降级
engine/library.js    案例库检索：搜索、分类、分页、排序、统计（纯函数）
src/page.html        三屏路由 + 首页 + 案例库 + 手机模拟 + 设置面板
build.js             单文件打包
tests/               55 项单元测试 + 72 项冒烟测试
dist/scam-sim.html   ★ 交付物，双击运行（约 124KB）
```

## 开发

```bash
node --test tests/engine.test.mjs tests/ai.test.mjs tests/session-ai.test.mjs tests/library.test.mjs
node build.js
node tests/smoke.mjs
```

测试分工：

| 文件 | 数量 | 覆盖 |
|---|---|---|
| `engine.test.mjs` | 15 | 互动模式规则层 |
| `ai.test.mjs` | 13 | prompt 编译、输出清洗、配置校验、越界检测、接口调用 |
| `session-ai.test.mjs` | 10 | AI 模式集成与失败降级 |
| `library.test.mjs` | 17 | 案例库结构、搜索、分类、分页、**搜索不受分类影响** |
| `smoke.mjs` | 72 | 打包产物实跑：三屏路由、搜索、分类、展开、分页、互动模式、AI 接线、响应式断点 |

`build.js` 存在的原因是 ES module 在 `file://` 下会被 CORS 拦截，
而「双击就能用」是这个工具的硬需求，所以构建阶段把六个模块拼成单文件。

## 界面适配

三档断点：`≤940px` 侧栏改纵向堆叠、`≤760px` 首页入口单列、`≤640px` 手机外壳改为
`width:100% + aspect-ratio` 随屏自适应（固定 390px 在窄屏会横向溢出）。

## 局限

- 案例库为静态内置数据（30 条），不含真实案件当事人信息。
- 内置话术模式下，同一阶段的多次回复会有重复；开启 AI 可缓解。
- 风险检测基于关键词，对刻意隐晦的表述（如只给卡号后四位）不敏感。
- API Key 存在 localStorage，明文可被同源脚本读取。仅在自己信任的机器上使用。
- `file://` 下直连第三方 API 可能被对方的 CORS 策略拦截（浏览器限制，非代码问题）。若 Key 无效却连不上，可 `npx serve` 起本地服务再打开。
- 聊天记录会随 AI 请求发送给所配置的模型服务，演练中请勿输入真实个人信息。
- 复盘报告只在本页生成，不做持久化存储。
